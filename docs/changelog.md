# 更新日志

安装与下载使用原项目的公开脚本。完整历史及正式发布日期以 [GitHub Releases](https://github.com/zhu-hailin/chaoxing-ai-assistant/releases)为准。

## v1.32 · 2026-10-27

- 界面统一为白色底与蓝色品牌色，更新蓝色书本图标、题目卡片和状态展示，精简请求详情。
- 设置入口移至侧栏，新增独立账号信息页和“隐藏头像”开关；“其他功能”新增视频水印与已结课课程显示开关。
- 优化明确无任务尾页的等待，适配无任务点的内嵌阅读材料，保留任务完成确认与异常保护。
- 字体映射与图标完整内置，构建使用固定本地资源；减少单次题目解析的重复查询。

[查看正式发行版与完整脚本](https://github.com/zhu-hailin/chaoxing-ai-assistant/releases/tag/v1.32)。

## v1.31 · 2026-10-24

[查看正式发行版与完整脚本](https://github.com/zhu-hailin/chaoxing-ai-assistant/releases/tag/v1.31)。

- 课程首页启动：通过原生入口进入学习页，交接本次配置与启动身份。
- 首页目录同步：展示章节状态，定位并直达首个未完成或需核对的章节。
- 课程队列：从个人空间勾选课程，按原列表顺序逐门处理，保留逐门结果。
- 待刷滚轮：将任务预览与刷课设置、章节目录分为三个栏目。
- 菜单与界面：课程菜单动态读取和隐藏、个人空间默认打开课程。
- 展示反馈：课程进度条、连接加载状态、禁用原因及无任务点课程灰显。
- 程序 Logo：统一使用绿色像素书本，悬浮窗显示透明图标，保留拖动与恢复面板操作。

## v1.30 · 2026-10-23

播放与面板体验优化：

- 新增固定与随机视频间隔。
- 增加强制连续播放及脚本内暂停／继续，优化后台意外暂停恢复。
- 优化章节目录、完成比例、状态展示及定位高亮。
- 设置分为工具、模型与开发者页面。
- 项目介绍支持拖动，打开时保持背景亮度。

[查看 v1.30 发行版](https://github.com/zhu-hailin/chaoxing-ai-assistant/releases/tag/v1.30)

题目识别与结果操作升级：

- 提供题号定位、未完成筛选、单题复制与原图查看。
- 完善未完成重试、结果暂存恢复及预填校验。
