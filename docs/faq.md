# 常见问题

## 安装后没有显示入口

依次确认：

1. 浏览器中的 Tampermonkey 已启用。
2. “学习通 AI 助手”脚本已启用，并允许用户脚本运行。
3. 已刷新整个学习通页面，而不是只刷新内部章节 iframe。
4. 当前处于已适配的个人空间课程列表、课程首页、学习页、测验或作业页面。

还可查看[安装教程](install.md)。不同学校的页面结构可能需要适配，反馈时附上页面类型及脱敏截图。

## 官网截图与安装后的菜单不同

官网按已发布的 v1.31 介绍，公开安装脚本由原项目发布。先核对当前脚本版本，并从[发行版](https://github.com/zhu-hailin/chaoxing-ai-assistant/releases)查看更新；不同页面也会按能力显示不同入口。

## 脚本免费，为什么还需要 API Key

脚本采用 MIT 协议免费提供。AI 分析、图片识别和视频信息识别使用你选择的模型服务，额度与费用由相应服务商决定。

## 模型列表获取失败或提示 401／403

核对服务商、Key、接口地址和账户权限。自定义接口应填写到 API 前缀，并按提示设置 Tampermonkey 域名白名单。避免把 Key 发到 Issue 或公开聊天中。

## 为什么模型看不懂图片

检查当前模型是否支持图片输入、图片是否成功加载，以及能力检测结果。使用[模型配置](guide/models.md)中的图片能力检测会实际调用接口。

## 预填与自动提交有什么区别

预填把答案写入作答区。作业通常由你核对后保存或提交；自动学习中的章节测验，只有在本次明确授权后才自动提交。已有不同答案受到保护。

## 结束了，为什么还有未完成任务

处理结束可能仍包含人工待办、跳过、超时或待解锁章节。查看详细报告，并以学习通原生任务完成标记为准。

## 顺序解锁的章节会怎样处理

助手识别平台提供的锁定证据，等待既有前置任务完成与解锁；到达明确边界时记录待解锁内容。课程队列可保留该结果并进入下一门，详见[课程队列](guide/course-queue.md)。

## 从哪开始会自动进入下一门课程

只有从个人空间课程列表勾选课程并开始的运行才属于课程队列。从具体课程首页、章节目录或学习页独立开始时，范围限于本课程。

## 课程为什么显示“无任务点”或置灰

课程列表按当前任务统计和可选资格显示状态；原生未提供有效任务总数的项目可显示“无任务点”。具体课程的空目录识别还会结合加载状态、任务统计和原生提示核对。

## 遇到人脸识别、验证码或异常停止

在原页面完成人工处理，再查看助手报告。身份异常、不明确的提交结果及保护性停止会中止队列，保留实际状态。

## 倍速为什么没有到 2 倍

助手只选择播放器提供的档位，最高不超过 2 倍。播放器没有相应档位时使用其可用档位；开启视频信息识别时保持原速。

## 能在手机上运行吗

官网适配手机阅读。脚本主要面向电脑网页端 Chrome／Edge 配合 Tampermonkey 使用；不同手机浏览器的扩展能力与平台页面结构存在差异。

## 如何反馈问题

提供脚本版本、页面类型、复现步骤、底部提示及必要的脱敏截图，提交到[项目 Issues](https://github.com/zhu-hailin/chaoxing-ai-assistant/issues)。需要更多细节时，可使用运行摘要或错误报告，并先检查其中信息。
