# 课程队列

课程队列入口位于个人空间的课程列表。“学习通AI助手”与“学习规划助手”、搜索区域处于同一行。

## 创建本轮队列

1. 打开学习通个人空间，进入“课程”。
2. 打开“学习通AI助手 → 待刷列表”。
3. 勾选本轮课程，可使用“全选”；检查进度及禁用原因。
4. 在“刷课设置”调整选项，再返回待刷列表开始。

[![课程选择、进度和无任务点状态](../assets/images/course-selection.png)](../assets/images/course-selection.png)
*课程按原列表顺序运行；开始后冻结本轮课程选择与设置。*

## 运行范围

队列复用当前标签页：先进入本门课程，经原生入口进入学习页，处理章节任务；本门结束后返回课程列表，重新读取下一门课程入口。

进入具体课程后，待刷列表展开到章节层级，标题栏显示橙色“课程模式”。这次运行仍属于原课程队列。

从具体课程独立点击开始的任务，只在本课程运行。

## 本门结束后会怎样

| 当前结果 | 队列行为 |
| --- | --- |
| 平台确认任务完成 | 保存结果，进入下一门 |
| 可处理任务结束，仍有人工待办 | 保留待办，进入下一门 |
| 明确的顺序解锁边界 | 记录待解锁章节，进入下一门 |
| 普通超时 | 根据“超时是否继续下一节”设置决定继续或停止 |
| 人脸、验证码、身份异常或提交结果不明 | 停止整个队列，保留现场 |
| 入口不明确、导航或交接失败 | 停止并显示具体原因 |

## 控制和恢复

队列模式提供“跳过本课程”，同时保留“跳过本章节”。停止会撤销队列继续权限，再取消当前任务；视频暂停只控制当前播放。

刷新或导航交接会核对队列、课程、账号及模型配置。失去有效交接或身份发生变化时，按提示重新处理。不要通过同时操作其他标签页代替正常换课流程。

## 自动提交与报告

自动提交只使用本次明确确认的授权，范围限定于本轮所选课程。逐门结果会保留完成情况与待办；重试按未完成项处理，学习时长与休息安排在本轮延续。

课程列表中的“无任务点”和“已结束”项目置灰。平台状态与目录的最终核对在具体课程内进行。
