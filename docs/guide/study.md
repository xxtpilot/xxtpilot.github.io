# 单课程学习

从具体课程首页、章节目录或实际学习页开始时，助手只处理当前课程。需要连续处理多门课程，请从[个人空间课程队列](course-queue.md)开始。

## 开始学习

1. 在当前课程打开“学习通AI助手”。
2. 进入“刷课设置”，按需调整学习选项。
3. 返回“待刷列表”，核对章节预览后点击“开始刷课”。

课程首页会先通过平台原生入口进入实际学习页，再交接启动已有任务流程。课程与账号身份不一致、目录未就绪或导航失败时会提示原因。

## 三个栏目

| 栏目 | 作用 |
| --- | --- |
| 待刷列表 | 显示章节滚轮及开始、停止、跳过、暂停等操作 |
| 刷课设置 | 配置跳过已学、超时处理、视频和测验选项 |
| 章节目录 | 搜索章节、查看状态、定位与手动导航 |

[![待刷列表中的当前章节与后续章节](../assets/images/study-queue.png)](../assets/images/study-queue.png)
*滚轮用于查看待刷内容；滚动选择本身不会启动任务或跳转章节。*

## 定位与跳过已学

开启“自动跳过已学”时，按已确认的平台状态跳过已完成内容；从课程首页启动可直达首个未完成或需要核对的章节，再检查章内任务。

关闭该选项后保留从头学习流程。“从当前开始”在课程列表和课程首页保持禁用，在实际学习页按原有规则使用。

## 视频、资料与倍速

视频提供强制连续播放、关闭声音、暂停／继续、固定或随机间隔等选项。开启倍速后，按播放器提供的档位选择最高且不超过 **2 倍**的速度；启用视频信息识别时保持原速。

资料阅读仍需等待平台完成确认。仅滚动到底、跳过或超时不会被直接视为完成。

## 自动提交章节测验

“自动提交章节测验”默认不携带旧授权。只有本次明确勾选并确认授权后，才在允许的章节测验流程中自动提交；取消、失败或过期后相应权限失效。

未授权自动提交时，章节测验按现有流程记录为待人工处理。遇到不确定作答或提交结果，需要人工核对。

## 停止与待办

- **停止／取消启动**：结束当前任务或待交接启动，运行中可能要求再次确认停止。
- **跳过本章节**：记录为主动跳过，继续按当前流程处理。
- **暂停／继续**：控制当前视频播放。
- **重试未完成**：针对报告中的未完成项继续处理。

顺序解锁课程按平台开放状态等待；达到明确锁定边界时记录待解锁内容。人脸识别、验证码、身份异常和不明确提交结果交由人工处理。
