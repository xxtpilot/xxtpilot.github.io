# 章节目录

课程首页和实际学习页的目录都可在助手中查看。目录来源于当前课程的原生章节内容。

[![章节目录中的完成与待完成状态](../assets/images/catalog.png)](../assets/images/catalog.png)
*可通过搜索框筛选章节，并使用定位和刷新操作。*

## 查找章节

- 输入章节标题或关键词，过滤当前目录。
- 目录有原生分组时可折叠查看，并展示已有的完成比例。
- 课程首页使用“定位未完成”，展开相关分组、清除遮挡目标的筛选并高亮目标。
- 实际学习页使用“定位当前”。

点击可用章节会执行原生导航，**不会自动开始学习**。任务运行期间，手动导航按钮按资格禁用，并提供原因。

## 状态含义

| 状态 | 含义 |
| --- | --- |
| 已完成 | 读取到平台原生完成证据 |
| 待完成 | 平台提供了未完成任务信息 |
| 无任务点 | 当前目录或任务统计提供了相应状态 |
| 待解锁 | 存在明确的顺序或权限限制 |
| 状态未确认 | 原生信息不足，需要进一步核对 |
| 入口未确认 | 尚未识别到可靠的原生导航入口 |

## 顺序解锁课程

首次待处理章节处于锁定边界时，助手保留该边界。进入学习页后继续使用既有完成确认与解锁等待机制，待解锁章节单独记录。

## 目录加载或刷新

目录 iframe 加载、替换或课程身份变化时，助手会更新目录来源。若持续显示加载状态，可使用“刷新”，并确认原生章节栏目已经打开。

空课程需要结合已加载目录、原生任务统计和平台提示识别。部分学校页面结构可能不同，可按[反馈说明](../about.md#反馈问题)提供脱敏信息。
