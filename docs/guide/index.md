# 使用指南

先完成[安装与首次配置](../install.md)，再按所在页面选择流程。

## 使用说明

以下说明与[项目 GitHub 使用说明](https://github.com/zhu-hailin/chaoxing-ai-assistant#使用说明)保持一致。

- AI 答案请自行核对；人脸识别、验证码及未适配的任务需人工处理。
- 完成状态以平台为准，跳过或超时的任务仍需完成。
- API Key 与学习开关保存在篡改猴存储中；更新脚本后请刷新课程页面。
- 无人刷课与自动提交可能影响学习记录或成绩，请遵守课程要求。详见[使用风险说明](https://github.com/zhu-hailin/chaoxing-ai-assistant/blob/main/docs/%E8%84%9A%E6%9C%AC%E4%BD%BF%E7%94%A8%E9%A3%8E%E9%99%A9%E5%88%86%E6%9E%90%E6%8A%A5%E5%91%8A.md)。

## 我想处理题目

进入章节测验或作业，打开助手，提取题目并进行 AI 分析。核对结果后再预填答案，保存或提交由相应流程决定。

[题目与答案 →](questions.md)

## 我想处理本课程

在具体课程首页、章节目录或学习页打开助手，调整设置后开始。运行范围保持在本课程。

[单课程学习 →](study.md)

## 我想依次处理多门课程

从个人空间课程列表打开助手，勾选本轮课程，按列表顺序运行。

[课程队列 →](course-queue.md)

## 先了解两个区别

**预填与提交**：预填将答案写入作答区。章节自动提交需要本次明确授权；已有不同答案受到保护。

**处理结束与平台完成**：报告会保留失败、人工待办和待解锁内容。平台任务标记是完成依据。
