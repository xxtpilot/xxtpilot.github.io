# 模型配置

打开 **设置 → 模型设置**。API Key 需自行准备，服务商根据你的账户和调用情况计费。

## 支持的服务商

| 服务商 | 接入方式 |
| --- | --- |
| DeepSeek | 预设接口 |
| OpenAI | 预设接口 |
| 通义千问 | 兼容接口 |
| Kimi | 兼容接口 |
| 智谱 GLM | 兼容接口 |
| 自定义 | 自行填写 OpenAI 兼容 API 前缀及模型 ID |

具体可选型号从服务商获取或由你配置。图片、思考与检索等能力以模型实际支持情况和检测结果为准。

## 预设服务商

1. 选择服务商，填写并保存对应 API Key。
2. 点击“获取模型”，从返回列表选择模型。
3. 按需使用“测试连接”或“检测图片能力”。这两项会实际调用接口并使用额度。
4. 在可用时配置深度思考、思考强度、网络检索和分析并发。

## 自定义接口

填写 API 前缀，例如：

```text
https://example.com/v1
```

地址填写到 API 前缀，模型 ID 单独填写。按页面提示将接口主机名加入 Tampermonkey 的用户域名白名单。

更换接口基础地址后，已有凭据可能需要重新确认授权。请核对接口提供者与地址，再保存对应 Key。

## 图片题与视频信息识别

图片题需要支持图片输入的模型。视频信息识别位于 **工具设置**，可选择识别模型和抽帧间隔；开启后会读取可用字幕、讲义及视频画面，并使用模型额度。

开启视频信息识别时，播放器保持原速。

## Key 保存在什么地方

API Key 和学习设置保存在 Tampermonkey 的脚本存储中。官网仅提供静态文档与安装链接，不接收或保存你的 Key。

使用模型功能时，相应题目、材料或图片会按流程发送到你选择的服务商接口。避免在问题反馈或截图中包含 Key 和个人信息。
